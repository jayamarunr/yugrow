# Design Reviews

Each review documents a design decision for the Yugrow Experience Preview.

## Structure

Every review answers:

- **Purpose** — What screen or experience was reviewed
- **What changed** — Before/after summary
- **Why it changed** — Rationale behind the change
- **Screenshots** — Visual reference
- **Score** — 1-10 across visual hierarchy, typography, spacing, accessibility, touch ergonomics, emotional impact, trust, craftsmanship
- **Decision** — Approved / Needs Work

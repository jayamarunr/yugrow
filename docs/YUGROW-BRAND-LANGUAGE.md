## 1. Brand Identity

### Who is Yugrow?

Yugrow is **confident but not arrogant.** Professional but not corporate. Warm but not casual.

| Attribute | Yes | No |
|-----------|-----|-----|
| **Tone** | Warm, confident, precise | Cheerful, sarcastic, robotic |
| **Professionalism** | Polished, credible | Corporate jargon, buzzwords |
| **Familiarity** | Direct, human | Overly casual, slang |
| **Energy** | Calm, deliberate | Hype, urgency, FOMO |
| **Innovation** | Purposeful, thoughtful | "Disruptive," "game-changing" |

### Personality spectrum

```
Corporate ───────●────── Casual
                 │
               Warm
             Professional
```

- **More like:** Stripe, Linear, Notion, Apple
- **Less like:** Salesforce, HubSpot, Monday.com

### Brand archetype

**The Connector.** We exist to bring the right professionals together at the right time. Not through algorithms that guess — through presence that's verified.

## 2. Tone of Voice

### Guiding principle

> Write like you're speaking to a busy professional who already understands their industry. Don't explain what they already know. Don't waste their time. Earn their trust.

### Voice dimensions

| Dimension | Approach | Example |
|-----------|----------|---------|
| **Clear** | Short sentences. One thought at a time. | "You attend an event. You meet someone valuable. Yugrow makes sure you don't lose them." |
| **Confident** | We know what we're building. No hedging. | "Professional Presence for the Real World." Not "We're trying to help professionals..." |
| **Warm** | Human, not corporate. Use contractions. | "You're checked in." Not "Your check-in has been completed." |
| **Direct** | Say what you mean. No fluff. | "Open app. Tap 'I'm Here.' Meet people." Not "After launching the application, select the check-in option..." |
| **Minimal** | Every word earns its place. | "Relationships outlive the event." |

### Voice by context

| Context | Tone | Example |
|---------|------|---------|
| Marketing site | Inspiring, bold | "Professional Presence for the Real World." |
| In-app copy | Direct, helpful | "You're checked in. 12 professionals are here now." |
| Error messages | Clear, calm | "Unable to connect. Check your connection and try again." |
| Notifications | Brief, actionable | "Rajesh wants to connect. Met at AI Summit Chennai." |
| Empty states | Warm, optimistic | "You're early. The first attendees will appear here." |

## 3. Vocabulary

### Always use these words

| Word | Context |
|------|---------|
| **Professional** | The person using Yugrow. Never "user." |
| **Connection** | A professional relationship. Never "friend" or "follower." |
| **Presence** | Being at an event, verified. Never "attendance." |
| **Check in** | The act of declaring presence. Never "register" or "sign in." |
| **Workspace** | The context a professional operates in. |
| **Relationship** | The long-term connection between professionals. |
| **Network** | The collection of a professional's connections. |
| **Event** | A professional gathering, meetup, conference, expo. |
| **Venue** | The physical location of an event. |
| **Live** | The real-time view of who's present right now. |
| **Opportunity** | A business possibility that emerges from a connection. |
| **Broadcast** | A message shared with your network (future product). |

### Avoid these words

| Avoid | Use instead |
|-------|-------------|
| User | Professional |
| Friend | Connection |
| Follower | Connection |
| Like | (not applicable) |
| Check-in (noun) | Presence (noun) / Check in (verb) |
| Register | Check in |
| Sign up | Create account |
| Login | Sign in |
| Feed | Live / Network |
| Post | Broadcast |
| Content | (specific: Message, Opportunity, Broadcast) |
| Dashboard | Home |
| Analytics | Insights |
| Monetize | (not used in user-facing copy) |
| Gamification | (never used) |
| Disrupt | (never used) |

## 4. Words We Never Use

These words damage the brand. They never appear in any Yugrow communication.

### Corporate speak
- Synergy, leverage, circle back, deep dive, bandwidth
- Actionable, optimise, holistic, paradigm
- Touch base, pain point, thought leadership

### Tech hype
- Disrupt, revolutionise, game-changing, groundbreaking
- Powered by AI (we say "AI suggestions" or nothing)
- Blockchain, Web3, metaverse

### Social media language
- Viral, trending, influencer, content creator
- Follow, like, share (in the social media sense)
- Engagement (as a metric)

### Manipulative language
- Limited time, act now, don't miss out
- Exclusive, secret, insider
- You'll love this, you won't believe

## 5. Writing Principles

### P1 — One thought per sentence

```
Bad:  Yugrow helps professionals discover business events, 
      connect with verified attendees, and build meaningful 
      relationships that started in person.

Good: You attend an event.
      You meet someone valuable.
      Yugrow makes sure you don't lose them.
```

### P2 — Show, don't tell

```
Bad:  Yugrow enables seamless professional networking.

Good: You tap "I'm Here." 12 professionals are at this event.
      You open a profile. You connect. You continue the conversation. 
```

### P3 — Active voice, always

```
Bad:  A connection request has been sent.

Good: You sent a connection request to Priya.
```

### P4 — Specific over abstract

```
Bad:  Connect with professionals near you.

Good: 8 professionals are at AI Summit Chennai right now.
```

### P5 — Short is not rude

```
Bad:  We're sorry, but it looks like the connection request 
      could not be processed at this time. Please try again later.

Good: Couldn't send request. Try again.
```

### P6 — Error messages are apologies, not explanations

```
Bad:  Error 500: Internal server error. The server encountered 
      an internal error and was unable to complete your request.

Good: Something went wrong. Please try again.
```

## 6. Product Naming

### The Yugrow Group

```
Yugrow Group
│
├── Yugrow CheckIn    ← Phase 1 (current)
├── Yugrow CRM        ← Phase 5
├── Yugrow Broadcast  ← Phase 4
├── Yugrow Builder    ← Future
├── Yugrow HR         ← Future
└── Yugrow Finance    ← Future
```

Like **Atlassian** (Jira, Confluence, Trello) or **Zoho** (CRM, Books, People).

### Naming rules

- "Yugrow" is the company. "CheckIn" is the first product.
- User-facing: "CheckIn by Yugrow" or simply "Yugrow"
- Internal / platform: "Yugrow Presence Platform"
- Never: "Yugrow App" (ambiguous)

## 8. Brand Application

### Logo usage
- Clear space: minimum 1× logo height on all sides
- Never rotate, stretch, or recolour freely
- On dark backgrounds: white version
- On light backgrounds: emerald version

### Colour application
- Deep Emerald (`#0F766E`) reserved for meaningful moments
- Never use Deep Emerald for decorative purposes
- Never place Deep Emerald text on Deep Emerald background

### Typography application
- Inter is the Yugrow typeface
- Never use multiple typefaces in the same composition
- Never use italic for body text

### Photography style
- Real humans in real environments
- Natural light, warm tones
- Candid over posed
- Desaturated with warm tint
- No stock photography clichés

# The Founder Test

> Before any feature ships, ask:

### 1. Would I use this at a real expo?

If not, don't ship it.

---

### 2. Would I proudly demo this to someone without explaining it?

If not, keep refining.

---

### 3. Does this reduce or increase cognitive load?

If it increases it, simplify.

---

### 4. Does this create trust?

If not, remove it.

---

### 5. Does this strengthen a business relationship?

If not, question why it's in Yugrow.

---

This document is worth more than hundreds of pages of architecture.
It is the founder's taste codified into five questions.
Every feature, screen, and interaction must pass this test before it ships.

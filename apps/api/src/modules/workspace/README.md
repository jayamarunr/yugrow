# Workspace Engine

## Purpose
Identity context management. Person acts as a Workspace.

## Data Model
- Workspace: PERSONAL, COMPANY, BRAND, NONPROFIT, COMMUNITY, EVENT, etc.
- Membership: Person's relationship to a Workspace (OWNER, EMPLOYEE, etc.)

# Yugrow Question Log

> **What we're trying to discover — not what we've already learned.**
>
> Every question here is unanswered. Evidence from real events will move it from "Open" to "Answered" — and the answer will shape what gets built next.
>
> `LEARNINGS.md` records what happened. This records what we're trying to find out.

---

## How to use this

1. Before each meetup, review the open questions.
2. Watch specifically for moments that could answer them.
3. After the meetup, update status and record decisions.
4. Only remove a question once it has sufficient evidence.

---

## Core Hypothesis

> **Can presence-first networking help professionals create better relationships than exchanging business cards or using LinkedIn during an event?**

If this proves false, much of Yugrow's roadmap needs to be reconsidered.

## Three Event Types to Validate

| Type | Size | What it tests |
|------|------|---------------|
| Startup networking meetup | 20–40 | Core networking loop, intimate setting |
| Workshop or seminar | 50–100 | Registration flow, structured event format |
| Conference or expo | 200+ | Scale, discovery, multiple simultaneous connections |

If Yugrow succeeds across all three, the model is general rather than accidentally optimized for one type of event.
